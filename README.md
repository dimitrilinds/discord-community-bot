## ✨ Características

- 🛡️ **Moderación completa** — kick, ban, silenciar, advertencias, anti-spam automático
- 💰 **Economía** — coins, daily, trabajo, robar, transferir
- 📊 **Niveles y XP** — sistema de experiencia con roles automáticos por nivel
- 🎉 **Bienvenida personalizable** — mensaje, canal, color, banner, DM
- 🏷️ **Auto-roles** — asignar roles automáticamente al entrar
- 🎮 **Diversión** — 8ball, dado, moneda, chiste, trivia, rps, abrazos, besos
- 🎫 **Sistema de tickets** — soporte con canales privados
- 🏆 **Sorteos automáticos** — se activan al alcanzar la meta de miembros
- 🌐 **Multi-idioma** — español, inglés y portugués por usuario
- ⚙️ **Configurable por servidor** — cada servidor tiene su propia configuración
- 📋 **Menú de comandos interactivo** — con botones por categoría

---

## 🚀 Instalación

```bash
git clone https://github.com/dimitrilinds/discord-community-bot.git
cd discord-community-bot
npm install
cp .env.example .env
# Editar .env con tu DISCORD_TOKEN
npm start
```
